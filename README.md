# iClean Zm

A mobile-friendly smart waste management web app prototype for Zambia, connecting households with local waste collectors and recycling centres.

## Run locally

Open `index.html` in a modern browser. No build step or external dependencies are required.

## Prototype features

- Responsive household dashboard with collection and environmental impact summaries
- Pickup booking form with waste categories, Zambian province selection, date and time preferences
- Collector tracking status and contact shortcut
- Recycling centre directory cards
- EcoPoints wallet and reward redemption interactions
- Collection history, illegal dumping report form, profile settings and notifications
- Zambian province options and safety note for electronic, construction, hazardous and medical waste

This is a front-end demonstration. Authentication, live GPS/maps, SMS OTP, payments, collector dispatch, and verified centre/authority integrations require a production backend and service-provider integrations.
